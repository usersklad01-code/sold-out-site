# sold-out-site

Baseline snapshot of the custom site template for the new Sold-Out store
(Bitrix), pulled from the live staging install before any edits.

- Source path on server: `/local/templates/main`
- Preview: `0102.vms.iaas.store`
- Admin: `35.vms.iaas.store/bitrix`

The `local/templates/main/` tree mirrors the template as it was on the server
at the time of the snapshot. This is the untouched baseline; later UI/UX fixes
are committed on top so every change has history and can be rolled back.
